# 🎮 Food Catch Game - APK Build Guide

## **तुम्हाला APK File कसे मिळेल? (How to Get APK)**

### **Step 1: Files Download करा** 📥

सर्व files download करा:
- `app.json`
- `package.json`
- `App.js`
- `.gitignore`

एका folder मध्ये सर्व files ठेवा. Example:
```
food-catch-game/
├── app.json
├── package.json
├── App.js
└── .gitignore
```

---

### **Step 2: GitHub Account बनाओ** (Free)

1. जाओ: https://github.com/signup
2. Account बना लो (email + password)
3. Login करो

---

### **Step 3: GitHub Repository बनाओ**

1. **github.com** पर login करो
2. अपने profile icon पर क्लिक करो
3. **"Your repositories"** चुनो
4. **"New"** button दबाओ
5. Details भरो:
   - Repository name: `food-catch-game`
   - Description: `Mobile Game - Healthy Food Catcher`
   - Select **"Public"**
6. **"Create repository"** दबाओ

---

### **Step 4: Files Upload करो GitHub पर**

1. अपने नये repository पर जाओ
2. **"Add file"** → **"Upload files"** दबाओ
3. सर्व 4 files upload करो:
   - app.json
   - package.json
   - App.js
   - .gitignore
4. **"Commit changes"** दबाओ

✅ अब तुम्हारा code GitHub पर है!

---

### **Step 5: Expo Account बनाओ** (Free)

1. जाओ: https://expo.dev/signup
2. Free account बना लो
3. Email verify करो

---

### **Step 6: EAS Build करो** 🏗️

1. जाओ: https://eas.io/
2. अपना Expo account से login करो
3. **"New Project"** दबाओ
4. GitHub repository select करो (`food-catch-game`)
5. Click करो: **"Create and build"**

**अब waiting करो... (10-15 मिनट लगेगा)**

---

### **Step 7: APK Download करो** ⬇️

1. Build complete होने का wait करो
2. Download button दबाओ
3. APK file तुम्हारे computer मध्ये download हो जाएगा

---

### **Step 8: Phone मध्ये Install करो** 📱

**Android के लिए:**

1. APK file को अपने phone तक transfer करो:
   - Google Drive पर upload करो
   - Email करो
   - USB cable से phone को connect करो

2. Phone मध्ये file खोलो
3. **"Install"** दबाओ
4. Permission दो
5. Installation complete होने का wait करो
6. **"Open"** दबाओ

✅ **Game शुरू हो गया!** 🎮

---

## **अगर Problem आए तो:**

**Problem 1: GitHub upload नहीं हो रहा**
- GitHub desktop app download करो: https://desktop.github.com/
- Woh easier है

**Problem 2: EAS Build failed हो रहा**
- देख कि सर्व files सही हैं
- Filenames exactly match करने चाहिए

**Problem 3: APK install नहीं हो रहा**
- Unknown sources से install करने दो
- Settings → Security → Unknown Sources ON करो
